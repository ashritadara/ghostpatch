# Frontend fonts

Cyberform Demo renders page and card titles. Oxanium renders descriptions, controls, evidence, and remaining interface text. Both are self-hosted and embedded in the standalone scene.

- CyberformDemo.otf: extracted from the user-supplied cyberform-demo.zip. Original readme: CyberformDemo-Readme.txt.
- Oxanium-Variable.ttf: weights 200–800, with its SIL Open Font License in Oxanium-OFL.txt. Source: https://github.com/google/fonts/tree/main/ofl/oxanium
- Snasm-Lt.otf and AsapCondensed-SemiBold.ttf remain available but are not selected by the interface. Snasm was supplied in snasm.zip, with Snasm-EULA.pdf.
