# Frontend fonts

Oxanium (variable, weights 200?800) is the robotic primary font. Asap Condensed SemiBold is used for subheadings. Files are self-hosted; the browser makes no requests to Google.

Official sources:
- https://github.com/google/fonts/tree/main/ofl/oxanium
- https://github.com/google/fonts/tree/main/ofl/asapcondensed

The corresponding SIL Open Font Licenses are included in this folder.
